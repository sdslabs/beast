## beast config

Run interactive beast configuration setup

### Synopsis

Creates the default Authorized Keys File and Global Beast Config file while prompting the user interactively whenever needed.

```
beast config [flags]
```

### Options

```
  -h, --help              help for config
  -y, --non-interactive   Run configuration non-interactively with defaults
```
